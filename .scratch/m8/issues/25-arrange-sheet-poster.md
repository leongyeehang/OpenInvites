# 25: Sections: the host orders the Poster's sections in an Arrange sheet, and guests see that order

**What to build:** An event keeps its arrangement and whether its album is on. The editor gains a sixth tool, Arrange, a design sheet with one row per section: its icon and name, Move up and Move down buttons that name the section and say where it went, and an On switch for the sections whose switch is the arrangement's own (Schedule, Announcements). Each press shows at once and is saved through one action under the event's row lock. The event page builds every section through the registry's drawings, and the Poster layout draws the placed list in order; an event never arranged looks exactly as it did. The editor's invitation shows the sections in that order, as glass placeholders that say what guests will see, so the live copy above the sheet moves as the host arranges.
