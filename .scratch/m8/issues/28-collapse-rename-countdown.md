# 28: Sections: a host renames and collapses sections, and adds a Countdown

**What to build:** A row in Arrange opens to its heading, typed in place with the default as its placeholder, and to a Collapsed switch where the section offers one. Guests read the host's heading in every layout. A collapsed section is a native disclosure in the Poster and the Broadsheet too, showing its heading and how many things it holds, opened with one tap and still open after the page refreshes. A section locked to the viewer is drawn open, since there is nothing in it to open. Countdown joins the sheet: off by default; switched on, it is a section of its own and the countdown leaves When (Poster, Thread) and the Broadsheet's facts. A placeholder in the editor opens Arrange at its own row.

## Notes for the implementer

- **(plan)** Countdown switched on while it is still last moves to just after Details, where a host looks for it; it is last in every default order only so that the Poster's entrance delays reproduce today's (ticket 24). Once the host has placed it, switching it off and on keeps its place, unless it is last.
- **(plan)** The heading is sent 600 ms after the last key, as the Settings sheet sends a capacity; the optimistic list and the row's name follow each key at once, the live copy after the save's `refresh()`.
- The disclosure needs no script: never pass `open` to a `<details>`, so React leaves the guest's choice alone across `refresh()`. The summary is the control; its `<h2>` keeps the heading ids the delete buttons send the focus to.
- A countdown on a cancelled event, an open date poll or an undated draft has nothing to count to: the drawing loads nothing and `placedSections` leaves it out.

How it landed, and where it differs from the text above:
- **The Heading field has no `maxLength`.** The dispatch (from ticket 24's review) overrules `maxLength={40}`: an input's `maxLength` counts UTF-16 units, so 40 emoji would stop at 20. The field cuts what is typed or pasted to 40 code points by script (`SECTION_LIMITS.heading`), and leaves a word being composed by an input method alone until `compositionend`. Browser proof: 41 emoji typed keep 40, and those 40 are saved (`sections.spec.ts`, "a renamed section").
- **The preview helper is `previewedSections`** (`src/editor/previewed.ts`, ticket 25's name); it takes a third argument, `dated`, and gives the countdown only then. `previewSections` takes `dated` too.
- **`EditorProvider` gains `setOpenRow` beside `openRow` and `openSection`**, since a row's own disclosure must open and close it from inside the sheet. `openSheet` closes any open row, so Arrange opened from the toolbar (or closed) starts with none open; `openSection(key)` opens Arrange at that row and brings it into view. `OpenArrange` takes `sectionKey`.
- **Ruling: a row opens only while it is on**, for its heading and, where `REGISTRY[kind].collapse`, Collapsed (`opens` in `arrange-sheet.tsx`). So a switched-off Who's coming still offers no radiogroup (ticket 26's test unchanged), and the Countdown opens, for its heading only, once it is on. Cost if wrong: one condition.
- The heading's default, the field's placeholder and the hint's `{name}`, is the section's heading in the event's layout (`EventPage`'s, e.g. "Comments", "Photos"), worked out on the server (`defaultHeadings` in `section-previews.tsx`) and passed to `ArrangeSheet` as `headings`, so the editor's `ClientMessages` gain no `EventPage` namespace.
- The heading is sent 600 ms after the last key (as the Settings sheet's `DEBOUNCE`), tidied as the server tidies it, empty as null; the row's name follows each key through a typed overlay, the list and the live copy after the save. Closing the sheet sends what is waiting; typing in another row sends the first row's at once.
- The collapsed summary's chevron turns with `motion-safe:transition-transform`; under reduced motion it turns at once. The event page's own `:focus-visible` ring is the summary's.
- `glassClasses()` is exported from `glass.tsx` for the Poster's `<details>`; `Glass` draws with it.
- The Countdown section's body is `CountdownFigure`, the Broadsheet's large figure, in every layout; its heading `EventPage.sections.countdown`. A cancelled event, an open date poll or an undated draft loads nothing, so it is not placed; with the section on, a cancelled event shows no countdown anywhere.
