# 27: Sections: the Broadsheet and the Thread draw the host's order

**What to build:** The other two layouts draw the placed list, each in its own idiom, through the same registry drawings as the Poster. In the Broadsheet, Details is the description section; the masthead, title and facts (When, Where, Host with the headcount, the countdown) stay in the header and the ballot beside it. In the Thread, the invitation card stays first and the composer last; Details is the description, When and Where bubbles kept together; the announcements are one bubble each, oldest first, and move as a group. A collapsed section in the Thread is a native disclosure showing its heading and a count, which is how its Comments are drawn by default. An event never arranged keeps each layout's order of today.
