Round 2: what is a setting

  1. Who runs it: a setting, off by default. Under More options. When on, the operator's display name and initials sit under the welcome line, like "Hosted by" on an event.
  2. Posters: a setting, all twenty by default. Under More options: all of them, only the ones picked, or one always. Uploading the operator's own poster is left for later.
  3. Emails: not a setting. Account emails always use the instance name ("Verify your email for Lim Family Invites"), so mail matches the page that sent it. An empty name means "OpenInvites" everywhere.
  4. Create an account: not a setting. It follows Registration. Invitation only hides it, since a host invitation's own link leads to sign-up.
