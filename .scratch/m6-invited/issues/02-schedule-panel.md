# 02: Schedule: the event page follows the clock

**What to build:** A Schedule panel on the event page in every layout, showing the items in the event's zone, grouped by day when they span more than one, with each item past, now or upcoming by the guest's clock, and, under the `minute` setting, the page re-reading itself every minute while the event is on.

## Notes for the implementer

- Do not fix the browser's clock for the states: the server's HTML would carry one set of states and the browser another. `page.clock` is only for running the interval forward.
- In the editor the Poster's `edit` mode shows only the rows (`poster-layout.tsx:87–91`), so the host sees the timeline through "See it as a guest", as with announcements today.
- `router.refresh()` re-runs the whole `EventPage` (about ten queries). `countsAsView` already ignores requests with the `rsc` header (`src/events/views.ts:14`), so views are not inflated; `redrawAllowed` limits only server actions. Two hundred open guest pages are about three renders a second; `reload` is the host's lever.
- Commit subject, e.g. `Schedule: the event page follows the clock`.
