# 05: The email proven by a code

**What to build:** When the host asks for it, a guest's email is accepted only once they have entered a six-digit code emailed to it. The code step is a step of the shared flow, presented by every layout. The guest list marks proven addresses.

**Blocked by:** 04 Contact details

If it wasn't you, ignore this email." No footer, no stop link: nothing is stored for the address until the code matches.

A reply that edits an unchanged proven email skips the step.

- [x] Docs: `configuration.md`, Mail section: the list of what the instance sends gains "a code to a guest proving their email, when the host asks for it"; the `RATE_LIMIT_MAIL` row adds "and each code sent to a guest to prove their email".
